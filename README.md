# Academic_Vocab_Organizer

## Project Goal
This program is a Java command-line tool that saves and organizes new vocabulary encountered from different courses, and users can search and review saved vocabulary.

## The Problem

The problem I'm trying to solve is that there isn't a simple way for me to remember and store new English vocabulary. I'm still developing my English skills, and there are many new terms that I have encountered across different courses during college, so I want to help solve the problem of keeping these new vocabulary organized and remember where I learned them.

## MVP Scope
- [ ] Add vocab words (word, definition, and course name)
- [ ] Save the vocabulary to a plain text file
- [ ] View saved vocabulary
- [ ] Search for a vocabulary word
- [ ] Review the vocabulary by courses

## How It Works

This program allows users to add new vocabulary, save them, organize them by courses, search a word, and also review the vocabulary based on courses. This program works with a plain text file.

## Tech Stack

- **Language:** Java
- **Libraries:** ArrayList and file I/O tools
- **Data Storage:** A plain text file
- **External tools:** None
